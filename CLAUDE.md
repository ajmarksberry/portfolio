# Portfolio 2026

Build a responsive portfolio website for AJ Marksberry, a senior UX and product designer.

## Technology
- Next.js
- TypeScript
- Tailwind CSS
- App Router
- Static-first implementation

## Design requirements
- Treat Figma as the visual source of truth
- Use semantic HTML
- Meet WCAG 2.2 AA accessibility requirements
- Use responsive, mobile-first layouts
- Create reusable components
- Avoid unnecessary dependencies
- Avoid excessive animation
- Preserve strong typography and generous spacing

## Figma MCP rules
- Use Figma MCP design context before implementing a selected frame
- Reuse assets returned by Figma rather than replacing them
- Do not add icon libraries when the Figma payload already includes the assets
- Implement one section at a time
- Compare the implementation against the Figma frame after each section
